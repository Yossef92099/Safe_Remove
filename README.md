# Safe_Remove 

A minimalist, high-performance CLI-based file-shredding utility designed for Termux / Linux. It provides both standard deletion and secure destruction by overwriting file contents with null bytes.

## Installation

Run the following commands in your terminal:

```bash
git clone [https://github.com/Yossef92099/Safe_Remove.git](https://github.com/Yossef92099/Safe_Remove.git)
cd Safe_Remove
bash install.sh
